Small Claims Copilot — App Map

A one-page guide to where things live in this app. It's a snapshot of commit 2c82bff, so later changes can make it drift; the code is always the source of truth.

What it does

It turns the scattered documents behind a California small claims dispute into a packet that keeps what you said apart from what your documents show. The AI reads and quotes; ordinary code decides what counts as backed, so the AI can't mark anything proven on its own.

Browser app

src/ — the three steps (Describe, Add evidence, Review packet), React components, and printing.

Shared rules

shared/ — the data model and the code that decides ✓ backed, key flags, next steps, and the timeline. Runs in the browser.

Server

server/ — reads uploads, keeps the API key private, and talks to Claude.

Outside the code

Claude API (reads documents and photos) · your browser's localStorage (saves each case) · hand-picked California Courts links.

One action, end to end: a key flag

In the Demo case you answer “no” to knowing where the other party does business, but the invoice lists their address. Here is how clicking Generate packet turns that into the first key flag.

  1. 1
    Browser · src/generate.ts → generatePacket

    Sends each unread document to the server (the unedited demo replays a saved run instead).

  2. 2
    Server → Claude AI · server/ai/extractFacts.ts

    Claude lists facts, each with an exact quote — here, the invoice's “2150 Alder Creek Rd, Sacramento, CA 95826.”

  3. 3
    Server code checks · verifyFacts + findExcerpt (shared/excerpt.ts)

    A fact survives only if its quote really appears in the document. Invented quotes are dropped and counted.

  4. 4
    Server → Claude AI · server/ai/analyze.ts

    Claude links your statements to facts that support or contradict them; validateAnalysis drops any ID that doesn't exist.

  5. 5
    Browser storage · src/state/caseStore.ts → saveCase

    The validated analysis is saved in localStorage with your case.

  6. 6
    Browser code checks · shared/packet.ts → assemblePacket, shared/flags.ts → confirmedByCode

    Rebuilt on every view. The flag is “checked by code” only because looksLikeAddress finds a street, state + ZIP, or PO box in the quote.

  7. 7
    What you see · src/packet/KeyFlags.tsx → KeyFlags

    “You said” next to “Your documents”, labeled “mismatch checked by code”.

A three-stop route through the code

A reference route (not toured together): open these in your editor in order to follow the flag above.

  1. The AI quotes, code checks the quote

    server/ai/extractFacts.ts — search for verifyFacts. Every fact needs a quote that findExcerpt finds in the document, and an amount or date must be written in its own quote.

  2. Code confirms the mismatch

    shared/flags.ts — search for confirmedByCode, then looksLikeAddress in shared/address.ts. If code can't confirm it, the flag is labeled “AI interpretation” instead.

    The rule, in short 
    if (statement.id === ANSWER_IDS.knowsLocation)
  return facts.some((f) => looksLikeAddress(f.excerpt));
// otherwise: a contradicting amount or date that isn't the one you wrote

  3. What you see

    src/packet/KeyFlags.tsx — the KeyFlags component picks its label from flag.basis ("checked" or "ai_interpretation").

A practice to reuse

Let the AI propose; let plain code verify. In this project the AI never decides what's backed. It returns quotes, and code checks each quote against the document (verifyFacts) and confirms mismatches it can see for itself (confirmedByCode).

The evidence: tests use a fake “obedient” AI that claims everything is proven (tests/shared/packet.test.ts, tests/server/injection.test.ts) and the packet still shows ⚠ your word only. In the live demo, the $500 vs. $600 deposit flag is marked “checked by code” because the amounts really differ (tests/shared/flags.test.ts).

On your next project: when an AI's answer matters, ask it for something checkable (a quote, an ID, a number) instead of a verdict, and write the small check yourself. Then test that check with a fake AI that gives the worst possible answer.
